# ESTADÍSTICA PRO (Versión 1.0)

Aplicación web de distribuciones muestrales para Ingeniería Industrial.

Módulos: 1. Población · 2. Medias muestrales (con y sin reposición) · 3. Probabilidades (normal) · 4. Proporciones · 5. Diferencias y sumas · 6. Guía y fórmulas

## Opción A: abrirla en tu computador

1. Instala Python desde https://www.python.org/downloads (marca "Add Python to PATH").
2. Pon `app.py` y `requirements.txt` en una misma carpeta.
3. Abre una terminal en esa carpeta y escribe:

```
pip install -r requirements.txt
streamlit run app.py
```

Se abre sola en tu navegador.

## Opción B: publicarla en internet (gratis, con enlace para compartir)

1. Crea una cuenta en https://github.com
2. Crea un repositorio nuevo (por ejemplo `estadistica-pro`) y sube `app.py` y `requirements.txt`.
3. Entra a https://share.streamlit.io e inicia sesión con GitHub.
4. Pulsa "Create app", elige tu repositorio, deja `app.py` como archivo principal y pulsa "Deploy".
5. En un par de minutos tendrás un enlace público para abrirla desde cualquier computador.
